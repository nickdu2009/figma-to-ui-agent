# AC1-AC10 验收证据矩阵

## 结论

截至 2026-07-24，本项目的本地实现、验证和 M3 执行框架已经完成，但整个项目尚未
达到最终完成状态：

- 已证明：AC1、AC2、AC3、AC4、AC5、AC6、AC7；
- 已冻结待盲测：AC8；
- 部分完成：AC10；
- 未完成：AC9；
- 当前 M3 状态：`frozen`；
- 当前外部门禁：`local_pass_external_gates_closed`。

本轮在八次独立明确授权后调用了真实 OpenAI 和 Figma。首次因 Pi JSON 输出放大
触发 20 MiB 上限，第二次因 bounded-loop 状态在 Pi 内部 `turn_start` 被错误重置；
第三次正常退出且 Figma 抽取成功，但没有保存 UISpec、执行比较或输出最终文本。
第四次通过新增审计明确定位为 Figma REST HTTP `429` 限流；第五次在加长 REST
重试窗口后仍受 `file` HTTP `429` 限流，并暴露模型重复调用 `inspect_figma`。
第六次确认重复 inspect 已被同请求失败关闭门本地拦截，没有再次访问 Figma。更换
Figma token 后，第七次越过 429 并执行到 validation，但三画板复合大画布与候选
desktop/mobile 视口不匹配，视觉差异超过 92%。第八次改用 `landingpage` 单画板和
`440x996` viewport，1 次迭代内通过完整 Flow。随后在人工确认校准结果和视觉阈值后，
已生成 `data/baselines/m3/freeze.json`，baselineId 为
`7233e8901294a6290bbc88a9b0cd52cf75f9b74ede0675824e577a1c4e2436e6`。没有修改依赖版本，
也没有执行 Git。第三次精确根因因旧审计信息不足保持未知；第四次限流根因已通过
加长 REST 重试窗口和新 token 解决，第五次重复 inspect 已通过同请求失败关闭门修复。

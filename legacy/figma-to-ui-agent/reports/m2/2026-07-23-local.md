## UISpec 与受控 Catalog

`load_ui_spec` 支持读取 current 或指定不可变修订。`save_ui_spec` 在保存前执行
严格 Schema、页面树、状态、动作、行为夹具以及 DesignBundle 跨文档引用校验，
并以 `baseRevision` 执行 CAS。

Catalog 只暴露以下固定组件：

- `Stack`、`Grid`、`Section`、`Dialog`；
- `Text`、`Image`、`Divider`；
- `Button`、`Input`、`Checkbox`。

Button、Input 和 Checkbox 支持可选静态 `disabled`。UISpec 省略该字段时保持原有
行为；Adapter 归一化为 boolean Catalog prop；React 使用原生 HTML `disabled`；
禁用 Button 不生成 `dispatch` ActionBinding。

唯一事件入口是 `dispatch`，只能执行 UISpec 中已声明的 `navigate`、`set_state`
和 `open_dialog` 动作。转换器只包含当前页面可达节点，并在渲染前再次通过
json-render Catalog 校验。UISpec 不存在 JSX、脚本、外部 URL、任意 CSS 或自由
事件字段。

每个 UISpec 页面通过 `sourcePageId` 精确关联一个 DesignBundle 页面。保存时要求
来源页面存在且不可重复，Preview 和视觉验证不再按数组位置猜测参考截图。

## 三栏 Preview

Preview 绑定 `127.0.0.1`，页面由以下区域组成：

1. Figma 页面参考截图；
2. json-render 当前实现；
3. 行为、键盘、控制台、视觉检查，以及 Actual/Diff 证据。

工具栏支持页面、视口、50%-200% 缩放和像素模式。桌面使用三栏工作区，900px
以下按参考、实现、检查结果顺序堆叠。按钮、选择器和输入框具有可见焦点。
禁用按钮、输入框和复选框使用原生语义，不可操作且不会进入 Tab 焦点序列。

Preview API 是只读接口：

- DesignBundle 和 UISpec 可按明确 revision 读取；
- 图片必须登记在所选 DesignBundle 修订中；
- run 证据必须登记在对应 `validation.json` 中；
- 项目标识、revision、run id、相对路径、文件名和符号链接均执行失败关闭校验；
- 响应禁用缓存并设置 `nosniff`。

验证 URL 固定 DesignBundle 和 UISpec 修订，因此验证期间发生并发保存也不会改为
渲染新的 current。

## render_and_compare

每次运行：

1. 加载当前有效 DesignBundle 和 UISpec；
2. 校验请求页面、视口、行为夹具和参考截图；
3. 在 `runs/<runId>/` 创建独立证据目录；
4. 启动或复用 localhost Preview 和 Chromium；
5. 固定视口、DPR、浅色模式、`zh-CN`、UTC、reduced motion 和 service worker
   策略；
6. 禁用动画、过渡和光标闪烁，等待字体就绪；
7. 截取实现画布并执行行为、键盘和控制台检查；
8. 在浏览器 Canvas 中逐像素生成红色 Diff；
9. 原子写入 expected、actual、diff 和 `validation.json`。

行为夹具已覆盖输入、复选框、按钮、跨页导航、文本断言和返回首页。键盘检查从
页面主体重新开始 Tab 顺序并要求首个交互控件具有可见焦点。控制台检查同时收集
console error 与 page error。

比较超过阈值时返回 `passed: false` 并保留证据，不伪造通过；超过像素上限或缺少
参考截图时失败关闭。

## Extension Agent Loop

Pi 仍只注册并激活：

1. `inspect_figma`
2. `load_ui_spec`
3. `save_ui_spec`
4. `render_and_compare`

默认服务在本地按需创建：

- `inspect_figma` 才读取进程环境中的 `FIGMA_API_KEY` 并调用 `FigmaInspector`；
- `inspect_figma` 的正式结构化输出保持简洁，同时向 Agent 补充有界的页面、节点、
  文本、布局、样式、组件、设计值、资产和最多 4 张已登记页面截图；
- UISpec 工具只访问项目存储；
- 比较工具只启动本地 Preview 和项目内 Chromium；
- `session_shutdown` 关闭浏览器和 Preview。

每轮强制 `save_ui_spec` 与 `render_and_compare` 成对，最多三次。第四次保存或未保存
直接比较会以 `bounded_loop_violation` 拒绝；重复保存相同 UISpec 会以
`bounded_loop_no_progress` 拒绝；一次比较通过后，后续修改会以
`bounded_loop_complete` 拒绝。三次均未通过时停止并报告最后证据。

## 剩余风险与 M3 边界

- 本地 M2 使用合成 DesignBundle/UISpec；尚未把真实 Figma 检查、真实 OpenAI 工具
  回合与 Preview 比较组合为一次端到端运行；
- M2 宽松阈值不代表视觉质量；M3 必须先用真实 Flow 校准阈值，再冻结配置；
- Figma scale=1 参考截图与非 1 DPR 视口可能存在尺寸差异，需在 Flow 校准中确定
  统一策略；
- 字体、locale、timezone、动画和 Chromium 已在当前主机固定；跨主机仍没有捆绑
  字体文件，不能声称跨操作系统像素一致；
- 进程在 `validation.json` 发布前异常终止时可能留下未完成 run 目录，但不会覆盖
  DesignBundle、UISpec 或既有验证记录；
- 三个未知输入盲测需要真实输入和外部调用边界，M2 本地结论不能替代该门。
